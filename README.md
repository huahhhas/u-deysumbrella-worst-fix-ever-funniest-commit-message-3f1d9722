## The entry

```
fix: race condition by adding a second, faster race condition
```

## How it works

`main.py` (pure Python stdlib, no network) writes the fixed commit message
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
